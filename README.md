# ☁️ Vân Quẻ Browser

**Trình duyệt huyền học Phương Đông.** Tử Vi, Tử Bình, Bát Trạch, Kỳ Môn, Hà Đồ Lạc Thư, Kinh Dịch và Vạn Niên Lịch tích hợp sẵn, chạy ngoại tuyến trên nhân Chromium.

🌐 Trang chủ & tải xuống: **https://vanque.pages.dev**

## Tải xuống

| Bản | Tệp |
|-----|-----|
| Windows — Bộ cài đặt (khuyên dùng) | [VanQue-Setup-x64.exe](https://github.com/datnpq/vanque-browser/releases/latest/download/VanQue-Setup-x64.exe) |
| Windows — Chạy ngay, không cần cài | [VanQue-Portable-x64.exe](https://github.com/datnpq/vanque-browser/releases/latest/download/VanQue-Portable-x64.exe) |

Yêu cầu Windows 10 / 11, 64-bit. Bộ cài chưa được ký số nên SmartScreen có thể cảnh báo: bấm **Thông tin thêm → Vẫn chạy**. Mã SHA-256 có trong `SHA256SUMS.txt` ở mỗi bản phát hành.

Kho này dùng để phát hành bản cài đặt và nhận báo lỗi qua **Issues**.

*Lý số để tham khảo, chiêm nghiệm — Đức năng thắng số.*
